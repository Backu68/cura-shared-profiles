# Eventide Shared Profiles for Cura

Shared printer/material capability management for UltiMaker Cura.

## v0.6.2 checkpoint

This checkpoint preserves the last tested pre-beta build: automatic transient slice-time capability resolution, non-persistent CuraEngine setting injection, single-extruder G-code hard ceilings for linear and volumetric flow, temperature offset, retraction overrides, and optional Klipper pressure advance.

Target: UltiMaker Cura 5.13.x / Plugin API 8.
